Para sincronizar datos entre dispositivos, ingresá tu Google Client ID del proyecto RENTAL ADM.

¿Cómo obtengo el Client ID?
  1. Ir a console.cloud.google.com
  2. Seleccionar proyecto RENTAL ADM
  3. APIs y servicios → Credenciales
  4. Crear credencial → ID de cliente OAuth 2.0
  5. Tipo: Aplicación web
  6. Orígenes: agregar null (para archivos locales)
  7. Copiar el Client ID generado
